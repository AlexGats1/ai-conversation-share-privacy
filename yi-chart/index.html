Privacy policy for Yi Chart · Local Charts & AI

Publisher: Alex&T. Applies to version 0.3.2–0.4.0. Updated October 14, 2026.

Information handled

The extension handles dates, times, gender selections, casting numbers or line values, questions and notes you enter, together with calculated charts, rules, AI prompts and replies. Birth details and free-text questions may contain personal information. For web interpretation, the task page address and delivery status are kept to reconcile the message and retrieve its reply. The extension does not read your full browsing history or unrelated conversations.

Local storage

Chart calculation and classical text reading run locally. Language preferences are stored on your device. The current chart, task, prompt, reply and API credentials are temporarily held in restricted extension session storage. Charts and interpretations you explicitly save remain in this browser; browser sync is not used. The developer does not operate a server that receives your chart, conversation or credentials, and uses no analytics or advertising trackers and does not sell your data.

Requests to Google

Only when you explicitly start an AI interpretation are the chart, relevant input such as dates, your question and necessary classical quotations sent to Google. The web channel fills and sends the prompt on the Gemini task page you authorize, using that website's existing sign-in state. It does not extract or copy passwords or cookies. The API channel sends the prompt and your API key directly to generativelanguage.googleapis.com for the available model you select. The key is not sent to web pages, included in chart exports or saved in long-term history.

Google processes requests under its own terms, privacy policy and the settings of the service and account you use. Provider fees and usage limits may apply. The developer cannot delete conversations or request records held by Google. See Google's Privacy Policy.

Website access

Optional access is requested when you first use the chosen AI channel and is used only for that task page or model request. Revoke website access in the browser's extension settings to disable the corresponding AI channel. Local chart calculation and source reading remain available.

Retention, export and deletion

Saved charts and interpretations remain until you delete them, clear extension data or uninstall the extension. Deleting a chart also deletes its saved interpretations; current task text may remain until the extension session ends. Unsaved session data and API credentials are not long-term history. Closing the browser or reloading the extension ends the session. You can also clear the API key in Settings and save the change. Chart exports include chart inputs and results, but not saved interpretation history. Delete downloaded files yourself. Manage conversations saved by the AI website separately on that website.

Limited Use

Our use of user data complies with the Chrome Web Store Limited Use requirements, including information received from Google APIs.

Purpose and contact

Data is used only for chart creation, source reading and interpretations you request. It is not sold or used for advertising, credit assessment or lending. We will update this policy and its date if data handling changes. For support or privacy requests, email ngomgabongp@outlook.com. Information you choose to send by email is used to handle that request. Do not send passwords or API keys.

易学排盘 · 本地盘面与 AI 隐私政策

发布者：Alex&T。适用版本：0.3.2–0.4.0；更新日期：2026-10-14。

处理哪些信息

插件处理你输入的日期、时间、性别、起卦数字或爻值、问题及备注，以及计算出的盘面、所用规则、AI 提示词和回复。出生日期及自由输入内容可能包含个人信息。使用网页解读时，还会保存该次任务的页面地址和发送状态，以便核对和取回。它不读取完整浏览历史或无关聊天。

本地保存

计算与典籍阅读在本机完成。语言偏好保存在本地；当前盘面、任务、提示词、回复和 API 凭证在受限扩展会话中暂存。主动保存的盘面和解读在此浏览器中持久保存，不使用浏览器同步。开发者没有接收盘面、聊天或凭证的服务器，也不使用分析追踪、广告或出售数据。

何时发送给第三方

只有明确开始 AI 解读时，当前盘面、相关日期等输入、问题和必要的典籍引用才会发送给 Google。网页通道在你授权的 Gemini 任务页面中填入并发送，使用网站已有登录状态；插件不提取或复制密码和 Cookie。API 通道将提示词及 API Key 直接发送到 generativelanguage.googleapis.com，以调用你指定的可用模型；API Key 不发送给网页、不写入导出盘面，也不存入长期历史。

Google 按自己的条款、隐私政策和你使用的服务／账号设置处理请求，服务可能收费或受额度限制。开发者无法删除 Google 端的对话或请求记录。Google 隐私政策：policies.google.com/privacy。

网站权限

首次使用某个 AI 通道时请求对应的可选网站权限，仅处理该任务页面或模型请求。可在浏览器的扩展设置中撤回网站权限；这会影响相应 AI 功能，但不影响本地排盘和典籍阅读。

保留、导出和删除

已保存盘面和解读保留到你删除、清理扩展数据或卸载插件为止。删除历史盘面会删除关联的已保存解读；当前会话中的任务文本可能持续到扩展会话结束。未保存的会话内容和 API 凭证不作为长期历史保存，可通过关闭浏览器或重载扩展结束会话。设置中可清空并保存 API Key。导出记录包含盘面输入与计算结果，不包含已保存解读历史；下载到磁盘的文件须自行删除。网站上的对话需在该网站另行管理。

有限使用

我们对用户数据的使用遵守 Chrome Web Store 的有限使用要求，包括通过 Google API 收到的信息。

使用范围与联系

数据仅用于本插件的排盘、来源阅读和用户主动请求的解读，不用于广告、出售、信用评估或放贷。若数据处理改变，我们会更新此政策与日期。隐私及支持联系：ngomgabongp@outlook.com。通过邮件联系时，你主动提交的内容仅用于处理该请求；请勿发送密码或 API Key。
