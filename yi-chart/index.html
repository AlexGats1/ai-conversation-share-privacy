Privacy policy — version 0.7.0

Publisher: Alex&T. Updated October 14, 2026. This policy covers version 0.7.0. Earlier versions 0.3.2–0.4.0 support only Gemini and do not include the new share preview; only features present in the installed version apply.

Local data

The extension processes the dates, times, gender, casting numbers, line values, questions and notes you enter, together with charts, classical quotations, prompts and replies. Charts and source reading run locally. Language, provider and channel preferences are saved locally. Unsaved charts, tasks, replies and each provider’s API key and model settings are held separately in restricted extension session storage. The state interface never returns keys to web pages. Unsaved credential drafts exist only in panel memory.

Optional AI requests

Only when you explicitly start an interpretation are chart inputs, facts, your question and necessary quotations sent to your chosen provider: Google for Gemini, OpenAI for ChatGPT/OpenAI API, Anthropic for Claude API, or DeepSeek for DeepSeek API. Requests go directly over HTTPS, with no developer relay server. API keys go only to the corresponding fixed API host: generativelanguage.googleapis.com, api.openai.com, api.anthropic.com or api.deepseek.com. Website subscriptions and API access are separate, and provider charges may apply. Website access is optional and requested for the selected channel.

Gemini and ChatGPT web channels use your signed-in browser session only on the authorized task page. The extension does not extract passwords, cookies, unrelated conversations or full browsing history. Claude and DeepSeek have API access only. Task records retain provider, API model when applicable, chart digest, prompt, reply, status, and task page URL when applicable. No automatic retry or provider fallback occurs after interruption. OpenAI requests use store:false; this is not a promise that providers retain no data.

Optional sharing

Share chart creates readable text or a PNG locally. Questions, notes, dates and AI replies are excluded by default and can be explicitly included. Copy writes the selected preview to the clipboard; saving an image downloads it. Neither action sends it to a developer server. Review the preview before sharing through another app. Hidden dates may still be inferred from chart values. Full JSON export remains separate. Delete downloaded images yourself and manage copies with their recipients.

Retention and deletion

Saved charts and interpretations remain in local browser storage until you delete them, clear extension data or uninstall. No browser sync is used. Deleting a chart deletes its saved interpretations. Current task content may remain until the extension session ends. Closing the browser or reloading the extension ends the session. Clear key in Settings clears only the selected provider. Keys never enter charts, exports, prompts or saved history. Exports contain chart inputs and results, not saved interpretation history; delete downloaded files separately. Manage provider-held conversations and API records with the relevant provider. The developer cannot delete their records.

Purpose and contact

The developer operates no analytics, advertising tracker or data-receiving server and does not sell personal data. Data is used only for local chart creation, source reading, storage and interpretations you request. Use of user data, including Google API data, complies with Chrome Web Store Limited Use requirements. Provider terms, account settings and privacy policies apply to AI processing. Contact ngomgabongp@outlook.com for support and privacy questions. Email content is used to handle your request; do not send API keys or passwords.

隐私政策 — 0.7.0

发布者：Alex&T。更新：2026-10-14。本政策适用于 0.7.0。此前 0.3.2–0.4.0 仅支持 Gemini，且没有新版分享预览；以所安装版本实际提供的功能为准。

本地数据

插件处理输入的日期、时间、性别、起卦数字、爻值、问题与备注，以及盘面、典籍引用、提示词和回复。排盘和阅读在本机完成；语言、服务商和通道偏好本地保存。未保存盘面、任务、回复及各家的 API Key 和模型配置分别放在受限扩展会话存储中。状态接口不会向网页返回密钥。未保存凭证草稿只在侧栏内存中保留。

自选 AI 请求

仅在明确开始解读时，输入、盘面事实、问题和必要引用才会直接经 HTTPS 发送给所选服务商：Gemini 给 Google，ChatGPT / OpenAI API 给 OpenAI，Claude API 给 Anthropic，DeepSeek API 给 DeepSeek。无开发者中转。API Key 仅发给对应固定主机：generativelanguage.googleapis.com、api.openai.com、api.anthropic.com 或 api.deepseek.com。网页订阅与 API 分别管理，服务商可能收费；网站权限按选择的通道请求，可在浏览器扩展设置中撤销。

Gemini 和 ChatGPT 网页仅操作获准任务页并沿用已有登录，不提取密码、Cookie、无关聊天或完整浏览历史。Claude、DeepSeek 仅支持 API。任务记录服务商、API 模型（如适用）、盘面摘要、提示词、回复、状态及任务网址（如适用）。中断后不自动重试或切换服务商。OpenAI 使用 store:false，但不承诺服务商完全不保留数据。

自选分享

分享盘面在本地生成可读文本或 PNG；问题、备注、日期和 AI 回复默认不附带，可主动选择。复制将预览内容写入剪贴板，保存图片下载到本机，不发送到开发者服务器。通过其他应用分享前请检查预览；隐藏日期仍可能从盘面推知。完整 JSON 导出另行保留；图片文件自行删除，已分享副本向接收方管理。

保留与删除

主动保存的盘面与解读在本机保留，直到删除、清除扩展数据或卸载，不使用浏览器同步。删除盘面会删除关联的已保存解读；当前任务内容可能保留至会话结束。关闭浏览器或重载扩展结束会话；设置中的“清除密钥”只影响当前平台。密钥不进入盘面、导出、提示词或保存历史。导出包含排盘输入与结果，不含解读历史；下载文件自行删除。平台上的聊天及 API 记录由用户向对应平台管理，开发者无法删除。

用途与联系

开发者不使用统计追踪、广告或接收数据的服务器，不出售个人信息。数据仅用于排盘、阅读、保存及用户要求的解读。用户数据（含 Google API 数据）的使用遵守 Chrome Web Store 有限使用要求。AI 处理适用服务商条款、账号设置与隐私政策。支持与隐私联系：ngomgabongp@outlook.com；邮件内容仅用于处理请求，请勿发送 Key 或密码。
