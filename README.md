## GitHub Pages

Publish the `main` branch from `/(root)` in **Settings → Pages → Deploy from a branch**. Enable HTTPS.

After deployment, the policy URL is:

https://alexgats1.github.io/ai-conversation-share-privacy/privacy.html

The root `index.html` contains the same policy so visitors can also open the site homepage directly. This repository contains static policy files only; it does not receive or process extension conversations.

## Updates

Keep `privacy.html` and `index.html` identical and upload `privacy.css` with them. When the extension's data handling changes, update the policy and its date before publishing that version. Keep the public URL stable.
